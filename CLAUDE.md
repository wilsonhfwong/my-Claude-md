# Project: CLAUDE.md Best Practices Guide

This is a documentation-only repository. No build system, no dependencies.

## Rules

- All docs use ATX headings (`#`, `##`, `###`). No setext (underline) headings.
- Numbered doc files preserve their prefix for ordering (e.g., `01-`, `02-`).
- Every sentence in a rule example must pass the Question Test: "Would Claude make a mistake without this?"
- Do not add filler content. If a section has nothing actionable to say, omit it.
- Example CLAUDE.md files in `examples/` must follow the practices described in `docs/`.
- Keep lines under 120 characters where practical.
- When editing docs, do not change the meaning of community-sourced claims without noting the change.
